# 產品需求文件 (PRD) - 拉屎冠軍爭霸賽系統

## 1. 專案概述

### 背景與動機
在現代忙碌且壓力龐大的生活中，腸胃健康往往被忽視。排便狀況是反應身體健康的重要指標之一（如布里斯托大便分類法）。然而，記錄排便習慣通常顯得枯燥乏味，難以持之以恆。
為了讓健康管理變得有趣，「拉屎冠軍爭霸賽系統」應運而生！本系統將排便記錄「遊戲化」與「社群化」，結合爭霸賽、好友排行榜與成就系統，並專為手機單手操作優化，讓使用者在馬桶上能以最流暢、最快速的方式完成記錄，並與好友一較高下，從中獲得樂趣與健康。

### 目標用戶
- 關注自身腸胃與消化道健康的現代上班族及外食族。
- 喜愛趣味社群互動、想與朋友分享生活點滴（即使是拉屎）的年輕族群。
- 希望透過遊戲化機制建立良好排便習慣的人群。

### 核心價值主張
- **極簡與單手友善**：專為馬桶上的單手操作場景設計，3秒內即可完成一次完整的排便記錄。
- **健康遊戲化**：將排便數據轉化為積分與稱號，讓健康管理不再枯燥。
- **社群趣味對戰**：與好友組隊或PK，激發定時排便的動力。

## 2. 功能需求

### 功能 1：快速排便紀錄表單（含布里斯托大便分類點選介面）
*   **功能描述**：提供一個適合手機單手操作的快速記錄頁面。使用者可快速選擇布里斯托大便分類（1-7型，搭配生動圖示與簡短描述）、記錄排便時間、顏色、形狀與備註。
*   **使用者故事**：
    *   作為 **使用者**，我希望 **在手機上能用一隻手的大拇指輕鬆點選大便外觀分類並送出**，以便於 **在剛拉完屎、手拿衛生紙的局限狀態下快速完成記錄**。

### 功能 2：爭霸賽與好友排行榜
*   **功能描述**：使用者可以創建或加入「拉屎爭霸賽」，與好友比較排便頻率、健康度得分（依據布里斯托分類的黃金第3、4型）以及持久度，並即時更新排行榜。
*   **使用者故事**：
    *   作為 **參賽玩家**，我希望 **能看到自己與好友在爭霸賽中的積分排行**，以便於 **激發鬥志，透過多喝水與多吃蔬菜來提升自己的排便健康度以奪冠**。

### 功能 3：排便健康統計看板
*   **功能描述**：以視覺化圖表展示使用者的排便歷史，包括每週/每月排便次數趨勢、最常出現的大便類型（布里斯托分類比例）以及排便時間分佈。
*   **使用者故事**：
    *   作為 **關注健康的使用者**，我希望 **能看到週報或月報的視覺化分析圖表**，以便於 **掌握自己的腸胃健康趨勢，並在就醫時提供醫師參考**。

### 功能 4：成就與稱號系統
*   **功能描述**：根據使用者的排便行為解鎖特定成就。例如：連續三天在同一時間排便解鎖「定時炸彈」、拉出黃金大便解鎖「煉金術士」、解鎖後可獲得特殊稱號並顯示於個人檔案中。
*   **使用者故事**：
    *   作為 **收集控使用者**，我希望 **在達到特定排便成就時獲得趣味稱號與勳章**，以便於 **在社群或排行榜上向朋友炫耀我的拉屎成就**。

### 功能 5：排便提醒與健康建議
*   **功能描述**：系統若偵測到使用者超過 48 小時未記錄，將推播提醒。同時，若連續數次大便分類偏向極端（如第 1, 2 型便秘或第 6, 7 型腹瀉），系統會自動提供對應的飲食與生活建議。
*   **使用者故事**：
    *   作為 **忙碌的使用者**，我希望 **在太久沒排便或大便不健康時收到貼心提醒與建議**，以便於 **即時調整飲食習慣，多補充水分或膳食纖維**。

## 3. 非功能需求

### 技術限制
- **後端框架**：Flask (Python)
- **前端渲染**：HTML5 + Vanilla CSS + Jinja2 模板引擎（不使用 TailwindCSS，改用精心設計的自訂 CSS 進行流暢排版與手機端優化）
- **資料庫**：SQLite (輕量、易部署)
- **響應式設計**：優先採用 Mobile-First（行動版優先）設計，元件大小與點擊區域需符合手機單手操作規範（點擊熱區至少 48px x 48px，且集中在螢幕下半部）。

### 效能與安全考量
- **載入速度**：頁面應極速載入，靜態資源需壓縮，確保在廁所收訊不佳時仍能快速開啟記錄表單。
- **隱私安全**：排便記錄屬於個人隱私，密碼需經過雜湊加密儲存，且使用者可設定是否將排便細節（如顏色、形狀）對好友保密（僅公開爭霸賽積分）。

## 4. MVP 範圍

| 功能模組 | Must Have (必要) | Should Have (應有) | Nice to Have (可有) |
| :--- | :--- | :--- | :--- |
| **帳號管理** | 使用者註冊、登入與基本資料設定 | 個人大頭貼上傳、防隱私洩露設定 | 第三方登入 (Google/LINE) |
| **快速排便紀錄** | **布里斯托大便分類點選介面 (單手操作優化)**、時間與顏色記錄 | 備註文字、排便時長計時器 | 大便照片上傳（AI 分析或僅作紀錄） |
| **爭霸賽系統** | 積分計算規則、基礎個人積分榜 | **好友爭霸賽房間**、即時排行榜 | 聯賽升降級機制、賽季制獎勵 |
| **統計看板** | 歷史記錄列表、最近 7 天排便次數圖表 | 布里斯托分類比例圓餅圖、異常提醒 | 導出排便健康報告 PDF |
| **成就系統** | 無 | 5 個基礎稱號與解鎖通知 | 自訂成就稱號背景框、成就分享圖卡 |
